# Instructor dashboard mockup (Lab 8)

The file `dashboard-mockup.svg` is a mockup with tokens in `<desc>`. It can be opened in a browser
or imported into Figma (File -> Place image). Design Mode requires a running application
(`npm run dev`). Data for the screen: `packages/shared/src/dashboard.example.json`.

Implementation requirements: tokens instead of "magic" values, accessible colors (contrast),
labels for screen readers, statuses conveyed not only by color but also by text.
